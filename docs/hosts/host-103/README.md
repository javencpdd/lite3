## 约定

“第三方/SDK”目录仅依据目录名、包元数据和启动脚本用途登记，不递归分析实现。`build`、`devel`、`install`、`log`、`.git`、`__pycache__` 等均为构建/运行时产物，不作为自研源码分析对象。

## 使用方式

1. 首次了解本机时阅读 `00-总体分析.md`，并与上级运维基线的采集时间对照。
2. 需要启动或排查某项功能时，再读取相应 ROS 1 或 ROS 2 专题；ROS 1/ROS 2 环境与 systemd 服务不可混用。
3. 网络、地图、VOA、Transfer、视觉跟踪或硬件驱动变更前，先阅读对应文件中的“风险与硬编码”章节，并在当前主机重新核验地址、服务和地图版本。

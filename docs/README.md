# 文档目录

`docs/` 是本仓库全部可维护内容的入口，按“单主机审计”和“跨主机运维”两个职责拆分。

## 文件与子目录

| 路径 | 内容 | 使用方式 |
| --- | --- | --- |
| [`hosts/`](hosts/README.md) | 103、120 两台主机各自的环境、脚本、模块和服务分析 | 需要定位某台主机的部署、依赖或风险时进入对应 `host-<id>/`。 |
| [`operations/`](operations/README.md) | 两台主机的实测配置汇总、角色对比和维护注意事项 | 日常维护前优先阅读，核对当前状态和变更边界。 |

## 使用约定

- 主机目录只保存该主机的报告与其索引；跨主机结论只写入 `operations/`。
- 文档中的服务状态、地址、端口和资源用量会随时间变化。引用时应保留报告中的采集时间，并在变更前重新实测。
- 新增一级目录时，必须新增同级 `README.md`，写明职责、文件清单与阅读方式。
